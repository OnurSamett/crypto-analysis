# R04: halving / four-year cycle phase — RECORD ONLY (not testable under the Gate)
Tarih / Date: 2026-10-22 · Durum / Status: REGISTERED as **NOT TESTABLE**; never a signal

**Özet (TR):** Halving döngüsü yalnızca 3–4 gözleme dayanır; kapı ölçütü 2'yi (≥30 bağımsız olay) doğası gereği karşılayamaz. Bildirim sinyali olarak asla kullanılmayacak.

**Hypothesis (as commonly stated).** Bitcoin returns depend on the phase of the roughly four-year halving cycle.
**Why it cannot be tested here.** There are only three complete cycles (2012, 2016, 2020) plus the current one; each unfolded in a different macro regime (rates, liquidity, ETFs from 2024). The Gate needs ≥ 30 independent events in dev; one event per cycle cannot reach that. Critiques (survivorship of "regularities that worked", n≈3) are summarized in the project notes; one peer-reviewed paper reports outperformance of a halving-anchored technical strategy on 2012–2025 data, but its independent-cycle count is not established in the abstract we read.
**Allowed use.** Descriptive context only (e.g. "time since halving" shown in a summary), clearly labelled as non-predictive. **Not allowed:** thresholds, filters or alerts based on cycle phase.
**Re-open condition.** Only if a pre-registered, higher-frequency, mechanism-based variant (not phase-by-calendar) is written as a new registry entry.

Variants K = 0. No returns will be computed for this entry.

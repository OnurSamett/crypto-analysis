# Registry (aday kayıtları)

Her aday sinyal kaynağı için bir dosya (`<kimlik>.md`), **test koşulmadan önce** commit'lenir. Şablon:

```
# <kimlik>: <kısa ad>
Tarih: <YYYY-MM-DD>
Hipotez:
Mekanizma (neden çalışmalı):
Olay tanımı:
Ufuk (tutma süresi):
Denenecek varyantlar (K = <sayı>): ...
Ölçüt:
Veri kaynağı / dönem:
```
Kural ve kapı ölçütleri: `../PROTOCOL.md` → Ek 3. English: `../PROTOCOL.en.md`.
